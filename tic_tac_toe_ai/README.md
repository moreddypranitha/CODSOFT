# 🎮 Tic-Tac-Toe AI

An advanced AI-powered Tic-Tac-Toe game built using Python.

This project implements:
- Minimax Algorithm
- Alpha-Beta Pruning
- GUI Interface using Tkinter
- Voice Commands
- SQLite Database
- Difficulty Levels
- AI Analytics
